# Vehicle Service Center Management System

## Project Overview

The Vehicle Service Center Management System is a Java Full Stack web application developed to manage vehicle service operations efficiently. The system helps customers and service centers manage vehicle servicing, booking, service tracking, customer information, and payment details through a user-friendly interface.

---

## Features

### Login Module

* User login page
* Basic authentication interface
* Forgot password option

### Dashboard Module

* Centralized navigation system
* Access to all management modules

### Customer Management

* Add customer details
* Store contact information
* Customer registration tracking

### Vehicle Management

* Add vehicle information
* Store license number and chassis details
* Vehicle type and fuel type management

### Service Preference Module

* Select service type
* Choose service date and time
* Pickup option support
* Additional notes section

### Service Status Tracking

* Track current service progress
* Delayed service handling
* Completion confirmation

### Payment Management

* Service charge calculation
* Taxes and discount support
* Multiple payment methods

  * Cash
  * Card
  * UPI
  * Net Banking
  * QR Code Payment
